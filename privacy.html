Privacy

wasdmod, its Mac and Windows apps, the zip’s scripts and this website · last updated 10 October 2026

wasdmod collects no data. It has no accounts, analytics, ads or tracking, and sends nothing about you or your computer anywhere.

What it reads

  • Keyboard and mouse, while the game is in front. The mod turns the keys of your layout into controller input inside the game. It doesn’t store or send what you press, and it ignores text you type into the game’s text boxes.
  • The game’s own keyboard settings (EnhancedInputUserSettings.sav), so the key layout editor can show and set the game’s keys. That file stays on your computer; the first change keeps a backup next to it.

What it stores, only on your computer

  • Your key layouts and language: in the game’s folder, and in ~/Library/Application Support/wasdmod (Mac), %APPDATA%\wasdmod (Windows) or ~/.config/wasdmod (Linux). The Windows app also keeps what its window needs in %LOCALAPPDATA%\wasdmod.
  • A short log, wasdmod.log, in the game’s folder: which settings file was loaded and when it switched modes. It never records what you type.
  • Record logs, only when you turn it on: a report file on your Desktop with the log, your layout and your system versions, for you to attach to a bug report if you choose.

When it goes online

  • Checking for updates (the Mac and Windows apps and the zip’s scripts, from GitHub): when the app or script starts, at most once a day, and when you click Check for updates, it asks GitHub’s public API for the newest release. GitHub sees your IP address and the app’s name and version, and its privacy statement applies.
  • Update now in the Mac and Windows apps, only when you click it: downloads the new version and its checksum file from GitHub Releases. The zip’s scripts download nothing: they offer to open the releases page in your browser.
  • The downloads from Nexus Mods never go online: they have no update check, and Get updates on Nexus Mods only opens the Nexus page in your browser.
  • In the Windows app and with the zip’s scripts, the key layout editor talks only to wasdmod on your own computer (127.0.0.1), never to the internet.
  • The editor opened as a plain web page (not inside the apps or by the zip’s scripts) loads two fonts from Google Fonts. The Nexus Mods copy doesn’t.
  • Downloads come from GitHub Releases, and this website is hosted on GitHub Pages; GitHub’s privacy statement applies there.

This website

  • The newest version number. The page asks GitHub’s public API once per visit which wasdmod release is the newest, to show its version number and link straight to its files. Your browser keeps that answer until you close the tab.
  • Your choices in the key map and the demo. The Controls section remembers the layout and system you last picked and any layout you make there, and the demo remembers its layout and difficulty. Both are kept in your browser’s local storage and never leave your device; Export layout saves the file straight to your computer.
  • Nothing else: no cookies, analytics, trackers, or fonts and scripts from other sites. The little game on the page runs entirely in your browser.
